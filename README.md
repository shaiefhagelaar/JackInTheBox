# Intro 
The video below shows how to set up a clawbot as a personal AI assistent on a VPS (Virtual Private Server). It's a basic set up to get a bot running on a server which I'll use to help me out with some cybersecurity stuff. Do note that this is at your own risk. Know your ethical boundaries.
